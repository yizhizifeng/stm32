========================================================================
 F407 最小系统板 —— 点灯工程（STM32F407VET6）
========================================================================

【这个文件夹里有什么】

  User\main.c          极简流水灯（推荐先用这个验证硬件）
  User\main_full.c     完整花样版（4 种花样轮播，验证通过后再用）
  Start\               启动文件和头文件（已从 Keil 的 Pack 里复制好）
  Start\CMSIS\         Cortex-M4 内核头文件
  说明.txt             本文件

  LED 接法：3.3V -> 1K -> LED阳极 -> LED阴极 -> PE0/PE1/PE2/PE3
           ★ 低电平点亮：PE 输出 0 = 亮，输出 1 = 灭


========================================================================
【关于启动文件】
========================================================================

  ★ 如果你在 Keil 的 Run-Time Environment 里勾了：
        ☑ CMSIS  -> CORE
        ☑ Device -> Startup
    那么启动文件和 system 文件已经自动加进工程了，
    在 Project 窗口里能看到：

        Target 1
         ├── Source Group 1
         │    └── main.c
         └── Device                     ← 这个分组由 RTE 自动生成
              └── startup_stm32f407xx.s

    Start\ 文件夹空着也没关系，不用管。


  ★ 如果你没用 RTE（手动建工程），Start\ 里已经放好了这些文件：

        startup_stm32f407xx.s      启动文件
        system_stm32f4xx.c         SystemInit
        system_stm32f4xx.h
        stm32f4xx.h                寄存器总头文件
        stm32f407xx.h              器件头文件（被 stm32f4xx.h 包含）
        CMSIS\core_cm4.h           内核定义
        CMSIS\cmsis_compiler.h     等

    手动建工程的步骤：
        1. 右键 Source Group 1 -> Add Existing Files
           把 .s 和 .c 都加进来（.h 不用加）
        2. 魔术棒 -> C/C++ -> Include Paths 添加：
             .\Start
             .\Start\CMSIS
        3. Define 填：STM32F407xx


========================================================================
【Keil 里怎么建工程】
========================================================================

 1. Project -> New uVision Project
    保存到本文件夹：D:\stm32\F407_点灯\Project.uvprojx

 2. 芯片选 STM32F407VE

 3. 弹出 Run-Time Environment 窗口：
      勾选  CMSIS -> CORE
      勾选  Device -> Startup
      OK

 4. 把 User\main.c 加进工程：
     右键 Source Group 1 -> Add Existing Files -> 选 main.c

 5. 魔术棒（Options for Target）：
      Target 标签：
        Xtal (MHz): 8
      C/C++ 标签：
        Define：STM32F407xx
        Optimization：-O0
      Debug 标签：
        选 ST-Link Debugger -> Settings -> Port 选 SW
      Flash Download 标签：
        勾 "Reset and Run"

 6. F7 编译，F8 下载


========================================================================
【接线（ST-Link 烧录）】
========================================================================

  ST-Link          H1 排针
  --------         ---------
  SWDIO     -----  2 脚
  SWCLK     -----  3 脚
  GND       -----  4 脚
  3.3V      -----  不要接！（板子用 USB 供电，接了会打架）

  H1 脚序：1=3.3V  2=SWDIO  3=SWCLK  4=GND


========================================================================
【上电前必做】
========================================================================

  1. 断电，万用表蜂鸣档量 3.3V 和 GND —— 不能响（响了就是短路）
  2. 上电，直流电压 20V 档量：
       USB 座 VBUS  = 5.0V
       D1 右焊盘    = 4.6V 左右
       3.3V 排针脚  = 3.25~3.35V
  3. 电源指示灯 LED1 应该亮

  以上正常，再烧程序。


========================================================================
【烧录成功后应该看到】
========================================================================

  main.c（极简版）：
      PE0 亮 -> PE1 亮 -> PE2 亮 -> PE3 亮 -> 循环
      每颗约 200ms

  如果一颗都不亮，按顺序查：
      ① 量 3.3V
      ② 量 PE0 对 GND：应该在 0V 和 3.3V 之间变化
         有变化 = 程序在跑，问题在 LED/电阻
         一直 3.3V = 程序没跑（查 BOOT0、复位）
      ③ 量 LED 两端：亮的时候约 0.3~0.5V（红色 LED 约 1.8V）


========================================================================
【常见编译错误】
========================================================================

  GPIOE undefined            -> C/C++ 的 Define 没写 STM32F407xx
  找不到 stm32f4xx.h          -> Include Paths 里没加 CMSIS 路径
  Undefined symbol SystemInit -> 没加 system_stm32f4xx.c
  Undefined symbol Reset_Handler -> 没加 startup 文件
  Undefined symbol main       -> main.c 没加进工程，或函数名拼错
